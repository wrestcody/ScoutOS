# SCN Scout API Documentation

This directory contains references for the SCN Scout API.

## Interactive Docs
The interactive Swagger UI is served dynamically by the application. To access it:
1. Clone the repository.
2. Run `npm install` and `npm run dev`.
3. Open [http://localhost:3000/api/docs](http://localhost:3000/api/docs) in your browser.

## Static Specification
You can find the full OpenAPI 3.0 specification file in the root directory:
[swagger.json](../../swagger.json)
